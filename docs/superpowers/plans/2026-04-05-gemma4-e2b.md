### Task 5: Write gemma4_rope Ea kernel

**Files:**
- Create: `kernels/gemma4_rope.ea`
- Modify: `src/kernels/ffi_inference.rs` — add symbol

**Context:** RoPE applied in-place. Takes precomputed cos/sin tables (computed in Rust per position). The kernel handles the rotation: `new_re = re*cos - im*sin`, `new_im = re*sin + im*cos`. Standard vs proportional mode is handled by Rust computing different cos/sin tables — the kernel is the same.

Data layout: Q/K vectors as `[head0_dim0, head0_dim1, ..., head1_dim0, ...]`. RoPE pairs: (dim0, dim1), (dim2, dim3), etc.
